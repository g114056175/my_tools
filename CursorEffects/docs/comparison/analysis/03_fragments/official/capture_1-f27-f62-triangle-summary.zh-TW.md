# capture_1 f27–f62 左下三角碎片局部驗證

本次只看 MP4 原始 60 fps PNG 的固定局部 ROI `x=78..144, y=110..165`，以 f26 同一 ROI 作 RGB 背景基準；未使用全畫面白色計數。追蹤圖涵蓋 f27–f62 共 36 幀，逐幀數據在 `capture_1-f27-f62-triangle-measurements.json`。

## 觀察

- f28–f35：同一視覺三角區由小變大，候選白色元件面積約 28→526 px，局部候選平均亮度約 238→249；這是生成/放大階段。
- f36–f37：三角仍在局部 ROI 內，亮度約 250，但右側青色環開始覆蓋。
- f38：候選 RGB 由近白（約 `[244,252,253]`）轉成青色（約 `[195,253,254]`）。局部形狀目視上 f40 仍可見、f41 本體幾乎消失、f42–f44 又在近似位置出現；f50–f51 幾乎消失，f53–f55 又可見。這是形狀層面的間歇出現觀察，不把整個 connected component 的平均亮度當作粒子 alpha。
- f39–f43 候選區受青色環覆蓋，f44–f48 與 f49–f58 又受環及底部亮帶影響；原始候選亮度的回升不能歸因於同一粒子重新變亮。
- f59–f62 的小幅回升（約 232）沒有重新變白，且候選元件邊界受環/軌跡影響。

## 判定

這個局部片段可支持「白色三角生成後轉為藍/青色並衰減/移動」，不能從實拍局部可靠證明同一粒子出現 source alpha 那種暗→亮→暗→亮。f44–f62 的亮度小幅回升仍是青色，且 ROI 內有環與軌跡重疊，應視為未判定，不可宣稱是 fragment 閃爍。

因此：source gradient 的 alpha 三次明暗交替仍是主要確證；capture_1 這顆實拍三角只提供白→青轉換的局部 corroboration，沒有足夠證據證明其自身重新變亮。

## 限制

f27 的三角太小且未通過白色候選門檻；f38 後青色環與底部亮帶進入 ROI。影片沒有粒子 ID，候選 connected component 可能在重疊時斷裂/合併；所有數據只代表局部候選，不是單一粒子真值。
