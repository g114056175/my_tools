# VideoPocket · 1.0.0

在 Chrome 小型視窗下載目前網頁提供的影片、音檔與字幕。需要 Chrome 120 以上；所有處理都在本機瀏覽器內完成，不需額外安裝程式。標題會依實際欄位寬度省略，不固定 24 字。

## 安裝與更新

1. 將 `VideoPocket.zip` 解壓縮，取得 `VideoPocket` 資料夾。
2. 開啟 `chrome://extensions`，啟用「開發人員模式」。
3. 點「載入未封裝項目」，選擇本 README 所在的資料夾；安裝 ZIP 中為 `VideoPocket`，該層直接包含 `manifest.json`。
4. 更新檔案後，在擴充功能管理頁重新載入 VideoPocket，並重新整理影片分頁。

## 使用

- 開啟影片網頁，再點 VideoPocket。選擇影片／音檔、格式與品質後下載；只有一個選項時直接顯示文字。「最佳」附上目前可選的最高解析度，例如「最佳（1440p）」。
- 同頁有多部影片時，可用頂部下拉選單切換並捲到該影片，或點右上角「在網頁選取影片」後點選播放器。Esc 取消，30 秒未選取會結束。瀏覽器支援時會自動重開 popup。
- 選單將有名稱的影片排在自動編號前，保留原本選取的播放器。
- Reddit 優先使用所屬貼文標題；Twitch 分別解析 Clips 與介紹影片的播放器識別；X 依影片／貼文識別取得 MP4 或 HLS，廣播回放另核對獨立廣播頁，避免引用貼文借用外層來源。各站仍依實際資料與權限判斷。
- 選片期間與完成後，擴充功能工具列圖示保持原樣，不加入選取或打勾徽章。
- popup 開啟時以綠框與名稱標示目前影片，關閉時移除。重新整理按鈕會重新偵測來源。
- 來源支援區間下載時，展開「進階設定」，拖動綠色起點／紅色終點，或輸入時間。時間精度為 0.1 秒；選取全長時下載全片。
- 影片與音檔可指定儲存位置；下載工作提供暫停、繼續與取消，實際能力依來源而定。
- 字幕支援 TXT、SRT、VTT 與純文字。Y 站請先在播放器啟用相同字幕；B 站依目前影片及分集查詢站方字幕，無法取得站方未提供的內容。

## 限制與處理方式

「找到影片，但無下載來源」表示已辨識播放器，尚未找到可與它核對的可用來源；「來源拒絕下載」表示來源請求被拒絕。社群網站可先正常播放，或進入單篇貼文後重試。無法保證所有網站、登入狀態及畫質都可下載。

影片與字幕分別偵測；影片來源尚未配對或請求被拒絕時，已取得的字幕仍可擷取。

`blob:` 是瀏覽器內部播放識別，不能直接改成網站檔案網址。只有一個無影片 ID 的播放器時，工具會嘗試驗證目前頁面 JSON 中的媒體候選；實際格式、時長或播放器狀態無法核對時，仍會回報沒有可用來源。

畫質選項取決於實際取得的來源。完整畫質清單不會因播放器正在播放低畫質而被取代；MP4 可讀取到實際影格高度時，以檔案資料修正標示。未出現 1080p 不代表網站一定沒有該版本。

X 網頁標示的 GIF 若實際提供 MP4，工具會保留 MP4 格式，不自動轉成 GIF。

完整下載與一般影音合併使用 stream copy，保留來源編碼。精準區間裁切可能直接複製、僅重編邊界，或重編整個所選區間；這依來源、切點及瀏覽器編碼支援而定，處理時間也會不同。工具不處理 DRM、直播錄製或登入／付費權限繞過。

HLS／DASH 區間下載會選取涵蓋指定時間與解碼所需的分段；一般直連 MP4 也能在具備時間索引、且伺服器支援 HTTP Range 時局部下載。無可靠索引時仍只提供全片下載。HLS 分段持續收到資料時不因總傳輸超過 20 秒而中止；連續沒有資料才觸發逾時重試。精準裁切保留音畫完整性驗證。

資料分段寫入瀏覽器暫存磁碟，完成或取消後清理。這不是播放緩衝保存功能；瀏覽器重開後不保留續傳能力。大小未知不代表無法下載，下載結束後仍可能有處理與儲存階段。

影音處理完成後，若指定的儲存位置無法寫入，會保留已完成的檔案並改由 Chrome 下載管理員儲存。可能再次顯示儲存對話框，不必重新下載或處理影音；若仍失敗，診斷只保留固定的儲存階段與原因，不記錄檔案路徑。

儲存檔名會清除瀏覽器不接受的不可見字元，畫面上的影片標題不變。若瀏覽器仍拒絕檔名，會沿用已完成的檔案，以 `VideoPocket` 加原副檔名再嘗試儲存一次。

MP4 是容器格式。切點符合條件時優先直接複製；部分 VP9／WebM 可只重編開頭。相容的 H.264／MP4 可重編頭尾邊界、複製中段，輸出會解碼驗證開頭、接點及尾端。不適用或驗證失敗時回退精準轉碼，避免黑畫面、缺影格或時間軸錯置。

非常短的區間、長 GOP 或不相容編碼，仍可能重編整個所選區間。精度受影片影格與音訊封包間隔限制，HLS 局部下載不保證處理比下載快。一般 MP4 的索引式下載只減少所需網路資料，包含必要的前後解碼片段，並非只取得剛好等於選取長度的 bytes。

開啟工具先列出影片摘要，再只深入探索目前選中的影片；單一影片自動選取。共用解析規則、分批 Shadow DOM 登記及有限中繼資料佇列減少重複工作。佇列只保留媒體資料並去除重複回應，避免一般 API／統計流量擠掉播放資訊；身分、來源及必要的格式／時長屬性分別保留。選片後優先處理相符識別的資料，重試不重複消耗已解析腳本的額度；仍須通過精確配對才能採用來源。X 廣播可在選片時補讀目前文件中的串流 JSON，仍須核對貼文、廣播與播放器識別。探索達上限時停止新增工作，可重新選片或重新整理再試；不保存影片播放緩衝或建立網域學習紀錄。
