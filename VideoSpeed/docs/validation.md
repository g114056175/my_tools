## 本輪結果

- 未訪問的背景分頁不建立影片 Session；新增影片後沒有影片標記、DOM 探索或畫質寫入。
- 以 Chrome 真實分頁啟用事件切換，離開後的 10 秒內仍可補查新影片，iframe 使用相同期限。
- 實際等待超過 10 秒後，新增影片不再觸發探索；已初始化且持續播放的同一部影片仍可調速。切回後補查新片，保留舊片手動設定的速度。
- 三個 frame 初始共有 3 次設定請求；後續完整倍速儲存事件同步至新版本號，額外設定請求為 0。不完整事件仍保留補讀容錯。
- 舊頁更新與同版重新載入後可恢復操作，文件 token 與手動倍速保留；CDP 與 pageerror 監看未捕獲例外。
- 單元測試涵蓋快速分頁切換、舊活動回覆、監看暫停／恢復、待辦清理與倍速同步順序；頁面合成快捷鍵不會改速或寫入跟隨記憶。

更新測試比對載入副本與發布成品的核心檔案 SHA-256，均一致。安裝包只含 26 個執行檔案，不含測試、Node 相依套件或瀏覽器 profile。

## 驗證限制

- 無介面模式的可見性資料不可靠；本輪以 Chrome 分頁 active 狀態測試，未驗證作業系統層級失焦及其他未聚焦視窗。
- 使用者回報舊分頁仍新增 `Extension context invalidated`；上述隔離測試沒有重現該條件，不能視為已修復。
- 使用者先前回報 Facebook 基本動態播放及 YouTube 畫質套用正常；真實廣告、長時間捲動與所有網站組合未完整驗證。
- 原生工具列 popup 尺寸未完成自動驗收；本輪介面回歸使用實際渲染的 420px 擴充頁面內容。
- 畫質依播放器能力而定；即時 MediaStream 的倍速受平台限制。探索量測未換算為 CPU 使用率。
