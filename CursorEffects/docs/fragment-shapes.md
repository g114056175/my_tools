# 碎片樣式與後續擴充

2026-10-10。已提供三角形、心形、箭頭、星星、閃電，位於「色系」頁的「碎片樣式」，下拉選單使用向量圖示加文字。切換模板色不改變樣式；樣式會保存至設定。

| 樣式 | 方向 |
| --- | --- |
| 三角形 | 正向或倒向隨機 |
| 心形 | 固定正向 |
| 箭頭 | 上、右、下、左隨機 |
| 星星 | 固定正向 |
| 閃電 | 固定正向 |

五種樣式共用拖曳與點擊的生成、擴張、先長大再縮小、轉色、三次明暗回升與消散。碎片大小基準為2.2，按使用者指定百分比縮放。切換樣式保留現有粒子的年齡、位置與數量，不重新生成。方向及光暈使用固定規則。

## 實作與驗證

`src/Effects.cs` 將形狀編號與方向傳入Kind 2繪圖命令；C#與C++命令均為44 bytes。`src/Renderer.cpp` 在GPU初始化時建立五種幾何及各自96×96外側光暈快取，心形使用貝茲曲線，箭頭使用多邊形。每幀不建立新幾何或圖片。

粒子最多192顆，繪圖命令最多2048個；只更新效果附近的區域。功能與實際GPU驗證涵蓋五種形狀、2／1／4／1／1方向、拖曳與點擊、切換不重生及設定保存；短時效能量測結果見[README](../README.md)。

## 未來方向

其他內建幾何可沿用形狀編號、快取與共用生命週期。不同樣式若需要專屬動態，適合先加入小型樣式資料，再決定是否增加面板選項。

使用者上傳icon／符號尚未實作。可先支援透明PNG，限制解碼尺寸並快取GPU圖片；單色alpha遮罩套用模板色，彩色圖片保留原色。仍需匯入與儲存、無效檔案處理、GPU重建時重載及專屬光暈。字元也需先轉成快取圖，字型與emoji會受系統影響。

其他點擊效果列為未來開發。它們屬於點擊樣式，應與碎片樣式分開；目前保留既有波紋／圓弧點擊效果，尚未加入新的點擊樣式。
