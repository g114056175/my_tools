# Voice Capture Lite Native（原生 C++ 版）

Windows 聲音擷取與簡易音檔裁切工具。使用 Win32 自繪介面與 Windows 內建音訊 API；一般使用者下載單一 `VoiceCaptureLiteNative.exe` 即可執行，不需安裝 .NET、Python、C++ 編譯器、Qt、Electron 或 FFmpeg。

## 功能

- 錄製目前 Windows 預設耳機／喇叭播放裝置的聲音；不錄麥克風。Windows build 20348 以上額外顯示「指定視窗的音訊」來源。這個來源按程序及其子程序擷取，並非逐分頁隔離。
- 錄製、暫停與繼續；暫停時間不寫入音檔。錄音時顯示經過時間與即時波形。
- 匯入 WAV／MP3、拖放音檔或貼上檔案路徑；播放／暫停、播放進度、點擊波形跳轉。
- 直接在真實音訊波形上拖曳左右裁切把手；選取以外以灰色顯示。裁切時播放與匯出只使用選取區間。取消裁切不改音檔，確認裁切才覆寫工作暫存檔。
- 拖曳波形底部刻度調整可見秒數：向右延長，向左縮短，最短 5 秒、最長全長。提供「全部」與「建議 · 30 秒」。縮放後可用下方比例導航條平移或拉伸，完整顯示時會隱藏導航條。
- 波形區高度隨視窗尺寸排版，不再提供波形卡片下方的高度拖曳條。
- 視窗可調整大小，但有保留所有控制項可操作的最小尺寸；播放／錄製計時與裁切秒數以兩位小數呈現。
- 匯出 WAV（保留工作音檔的 PCM16／float32，不壓縮）或 MP3（128／192／320 kbps），預設儲存到「下載」。
- 清除、重新錄製、匯入新檔、確認裁切等會影響工作音檔的動作均有確認提示。匯入的原始檔不會被修改。

按鍵：`Tab`／`Shift+Tab` 切換控制項，`Enter` 啟用焦點按鈕；`Space` 播放／暫停、`Ctrl+R` 開始／結束錄製、`Ctrl+O` 匯入、`Ctrl+S` 匯出、`Ctrl+T` 裁切／取消裁切、`Ctrl+V` 貼上路徑、`Ctrl+0` 顯示全部、`Ctrl+1` 顯示建議視窗。數字裁切欄位仍可使用系統輸入法及一般文字編輯快捷鍵。

## 使用與音質

雙擊 EXE，選來源並按「開始錄製」，接著播放想擷取的片段；結束後可試聽、調整範圍並匯出。也可直接打開 WAV／MP3 當裁切工具。點擊音軌只跳轉，不會自己開始播放。

錄音優先採用播放裝置的原生混音格式：相容的雙聲道 44.1／48 kHz 裝置可直接保存 32-bit float 或 PCM16，不強迫重新取樣；其他格式會回退到高品質轉換的 44.1 kHz PCM16。匯入相容 WAV 時保留其格式；MP3 與其他 WAV 格式在匯入時正規化為 44.1 kHz PCM16。WAV 匯出保留工作音檔的取樣格式，float32 WAV 因此會比 PCM16 約大一倍；MP3 在編碼時轉為 PCM16，仍屬有損格式。來源本身若已是有損音訊，輸出 WAV 或 320 kbps MP3 都無法恢復原本不存在的細節。即使錄製靜音，也會保留有效的錄製時長。

本次音質修正改以 WASAPI 回報的整數裝置樣本位置接續封包，避免每包重新換算時間戳造成細小補零或丟樣本。原生 float32 可減少過早量化。程式沒有加入自動降噪，以免刪掉語音細節；來源影片、其他系統聲音或裝置本身已有的噪聲仍可能被正常錄下。WASAPI loopback 的資料來自 Windows 播放路徑，與最終類比輸出、耳機音效處理可能存在差異。

工作檔位於 `%TEMP%\VoiceCaptureLiteNative\capture.wav`，同時只保存一份；進行匯入、錄製、確認裁切或匯出時，可能短暫出現 `.pending` 檔，成功後取代工作檔。原本 WPF 版的暫存檔不會被覆寫。

## 從原始碼建置

需求：Windows 10／11 x64 與 LLVM-MinGW（`clang++`、`llvm-windres`）。在 PowerShell 執行：

```powershell
./build.ps1
./tests/run.ps1
./tests/run.ps1 -Capture
```

輸出為 `dist/VoiceCaptureLiteNative.exe`。`-Capture` 會用目前預設播放裝置做短暫錄音測試；不會自動清除測試資料。發佈時只需提供 EXE。UI 繪製、WAV、播放、錄音、MP3 均使用 Windows SDK／系統元件；編譯採靜態連結 C++ 執行環境，沒有非 Windows 的執行時 DLL。

## 驗證與限制

本版 EXE 仍約 0.6 MiB；WPF v2.2.0 自含執行環境版為 66,337,365 bytes（約 63.26 MiB）。體積下降來自移除隨檔附帶的 .NET／WPF 執行環境，波形與音訊功能仍保留。

已在 Windows 10 build 19045 驗證：PCM16／float32 WAV 讀寫與樣本級裁切、Media Foundation 匯入、128／192／320 kbps MP3 回讀、兩種 WAV 播放、系統 loopback 錄音與暫停時間、裁切及縮放畫面。短錄音測試的封包對齊補零／丟樣本數由數百個降至零；此結果只證明測試條件下消除了該種斷續，並非對所有來源的主觀音質保證。Windows 11／build 20348 以上的指定程序擷取目前沒有實機驗證；若裝置不支援，來源與視窗欄位會隱藏。實機截圖見 [preview.png](preview.png)。

目前原生版的自繪按鈕可用滑鼠、Tab／Enter 與上述快捷鍵操作；原生下拉欄位、數字輸入框與檔案對話框也可用鍵盤。字型抗鋸齒、下拉清單邊框與 WPF 版不會逐像素相同。可執行檔尚未簽章；公開 GitHub 原始碼前，請由維護者選擇專案授權。
