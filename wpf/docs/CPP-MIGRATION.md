# C++ 原生版簡短計畫

狀態：提案，尚未實作。以 WPF v2.2.0 原始碼與介面截圖為行為基準。

## 目標與範圍

- Windows 10 / 11 x64，單一 EXE；不要求使用者安裝 .NET、Python、C++ 編譯器或額外 GUI 框架。
- 保留錄製／暫停、來源能力檢查、MP3/WAV 匯入、播放進度、裁切、縮放、確認與匯出。
- 保留主要版面、深藍背景、青藍／橘色波形、裁切灰遮罩、可拖曳把手與分色按鈕。
- 優先以小於 1 MiB 為目標；300 KiB～1 MiB 是工程估算，保守預留 1～2 MiB，不是已完成的量測承諾。
- 不加入 AI 模型、去噪、分離人聲、FFmpeg、網頁容器、線上帳號或額外格式。

## 模組替代

| 現行責任 | 原生版方案 |
| --- | --- |
| WPF Window、Grid、事件 | Win32 視窗／訊息迴圈，集中 Layout() 計算矩形與 DPI 尺寸 |
| XAML Button/ComboBox/TextBox | 標準 Win32 控制項；按鈕與選單 owner-draw 保留深色風格，文字輸入保留系統 IME 能力 |
| WaveformControl | 自繪音軌；GDI 雙緩衝先達標，若邊緣品質需要，再使用系統 Direct2D/DirectWrite |
| TimelineNavigator | 自繪比例範圍條，滑鼠捕捉、浮點時間映射、5 秒至全長的縮放限制 |
| WASAPI C# COM 宣告 | 原生 WASAPI + COM RAII，保留系統 loopback／程序樹模式與版本判斷 |
| PcmPlayer | winmm waveOut，固定數量緩衝、依裝置時計更新進度 |
| WaveFile / WindowsAudioCodec | WAV 串流與裁切、Media Foundation MP3；不附編碼器套件 |
| Open/Save/MessageBox | Windows 系統檔案與確認對話框，保留取消為安全預設 |

不用為了保留深色和圓角而帶入 WPF。系統字型與 Win32/Direct2D 已能支援大致外觀；細微字距、圓角抗鋸齒、選單陰影可能不同，不追求逐像素一致。

## 可簡化與不能刪除

可簡化：漸層／陰影／hover 動畫、複雜樣式繼承、多層 layout 容器、自訂檔案對話框、裝飾性圖示。現有介面本身已不複雜，這些主要省開發與維護成本，而非各自省幾十 MB。

不可為了小體積刪掉：確認覆寫、錯誤提示、暫停時間處理、緩衝生命週期、資源釋放、非同步工作執行緒、DPI／鍵盤焦點、真正 PCM 波形、播放器裝置進度、原檔保護。

## 分階段交付

1. **原生 UI 試作**：只讀合成 WAV，完成版面、真波形、裁切框、比例條與刻度連續拉伸。不得用隨機波形或截圖冒充控制項。
2. **WAV 編輯閉環**：播放／暫停／跳轉、選取播放、取消／確認裁切、WAV 匯出；所有不可逆動作要求確認。
3. **錄音與 MP3**：WASAPI pause/resume、無聲長度、程序能力限制、Media Foundation 匯入／匯出。
4. **驗證與封裝**：乾淨 Windows VM 執行、x64 靜態 CRT、移除偵錯符號、連結最佳化、檢查非系統 DLL 依賴、記錄 EXE／磁碟／記憶體量測。

每階段完成後才進下一階段。UI 回呼不得阻塞於錄音、解碼或寫檔；採明確的 Idle/Recording/Paused/Processing/Playing 狀態與 RAII 資源所有權。

## 驗收重點

- 對照 tests/ 中既有案例：PCM 裁切長度、MP3 128/192/320 回轉、播放終點及重開關。
- 新增原生等效測試；C# 測試不能直接作為 C++ 已驗證的證明。
- 暫停錄製期間不納入音檔；無聲期間保留有效長度；停止與取消啟動分開處理。
- 點擊波形不強制播放；裁切中播放／匯出只涵蓋選取；確認裁切才覆寫 Temp。
- 向右拉刻度擴大可見秒數，向左縮小；5 秒下限、30 秒建議、全長上限。
- 100%/125%/150%/200% DPI，最小視窗、長檔平移、鍵盤／輸入法與裝置拔除。
- Windows 10 與 Windows 11 各測；程序／分頁共用音訊的限制仍須告知。
