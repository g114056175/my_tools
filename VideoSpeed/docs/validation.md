## 探索量測

本地頁面初始含 6,023 個 DOM 節點。靜置與持續 8× 播放各觀察約 5 秒，內容腳本沒有新增 TreeWalker／querySelectorAll 探索；全域關閉後新增內容也沒有探索。

新增 2,000 項無影片內容時，舊版會觸發一次 document-root 補掃；新版 document-root walker 新增數為 0，改為分批處理新增子樹。極端積壓仍保留有界回退補查，避免漏掉影片。這是 DOM API 工作量量測，未量測 CPU 使用率。

## 實站與待驗證範圍

- 使用者已回報 Facebook 基本動態播放、部分其他網站及 YouTube 畫質套用正常；未將這些回報算入上述固定資料測項。
- 真實廣告、長時間連續捲動、串流平台及所有瀏覽器組合仍需持續驗證。
- 原生工具列 popup 視窗尺寸未完成自動驗收；目前版面檢查是實際渲染的擴充頁面內容尺寸。
- 畫質依網站暴露的播放器能力而定；即時 MediaStream 的倍速受平台限制。
