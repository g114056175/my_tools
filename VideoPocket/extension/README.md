# VideoPocket

在 Chrome 下載網頁影片、音檔與字幕，所有處理都在本機完成。需要 Chrome 120 以上。

## 安裝

1. 將 ZIP 解壓縮。
2. 在 `chrome://extensions/` 啟用「開發人員模式」。
3. 點「載入未封裝項目」，選擇本 README 所在的 `VideoPocket` 資料夾，再重新整理影片網頁。

## 使用

- 開啟工具後自動偵測影片；多部影片可用下拉選單切換，也可按選取按鈕指定網頁中的播放器。「↻」重新偵測。
- 在 Video 選擇格式與畫質，或在 Audio 下載／抽取音訊。畫質以短邊標示，自動降級不會覆寫原偏好。
- 展開 Clip download 調整起迄時間；需完整下載後裁切的來源會顯示黃色提醒。
- 在 Subtitles 預覽、複製或儲存 TXT、SRT、VTT。YouTube 可嘗試自動切換所選字幕後還原；Bilibili 使用站方字幕。
- 收起視窗後工作繼續；暫停、繼續與取消依來源支援情況提供。

「大小未知」不影響下載。找不到來源時，可重新偵測或在網頁中選取播放器。大檔需預留磁碟空間，瀏覽器重開後不保留續傳能力；不支援直播錄製。

### 區間擷取實作限制與未來考慮

來源有可靠索引且支援範圍請求時局部下載，其他合適來源可完整下載後裁切。即使時間戳已知，切點影格仍可能依賴區間外的畫面，須保留解碼前置資料並對齊影音時間軸。切點適合時直接複製或只重編邊界；不相容時可能重編整個所選區間。精度與處理時間受影格、音訊封包、GOP 及瀏覽器編碼能力影響。

大小使用已知位元組數，或確實對應所選影音組合的全片平均值；音軌組合不明及片段估值顯示未知。
